Questions

Does it cost anything?+

Sluice is free. Claude does the work on your existing Claude plan, and usage counts the same as it does in Terminal.

Do I need an API key?+

No. Sluice launches the claude you installed, signed in as you.

Does Sluice see or send my code?+

Sluice never calls an API itself. Claude Code does the work on your Mac, exactly as it does in Terminal; Sluice puts a window on it.

I already use the Superpowers plugin.+

Sluice has Superpowers built in. If it finds your plugin too, it warns you so skills don't load twice, and leaves the choice to you.

What do I need?+

macOS 26 or later on Apple silicon or Intel, and Claude Code installed and signed in.
